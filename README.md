The goal of this project is to develop a real estate management system with a clean architecture design.  The system will allow realtors  to manage property listings, calendars, and contacts . Registered users will be able to interact with the system by rating, favoriting, and providing feedback on listings, while unregistered users can browse properties.  

The system will be built using a .NET WebAPI backend (with MediatR, Fluent Validation, AutoMapper, and Entity Framework) and an Angular frontend.  The application will follow the CQRS (Command Query Responsibility Segregation) pattern alongside the Mediator pattern to separate read and write operations. 

Roles , authentication, and authorization are key elements of the solution, and the project will adhere to Clean Architecture principles. 

The codebase will be versioned and managed in Azure DevOps, with each phase being developed in a separate branch and submitted via pull request (PR) for review.
